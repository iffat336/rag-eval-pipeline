🔎 RAG Eval Pipeline — Live Demo

Hybrid search (semantic + BM25) with cross-encoder reranking, LLM-driven query decomposition, and a grounded, cited answer — powered by the pipeline in rag-eval-pipeline.

About this demo

This runs against a small fictional API documentation set (auth, rate limits, webhooks, and billing for a product called "Nimbus"). Try a compound question — e.g. "How does X compare to Y, and which should I use for Z?" — to see query decomposition split it into sub-questions before retrieving for each one.

To keep this demo affordable to run, usage is rate-limited per visitor and per day. If you'd like to run it yourself with your own API key, the full source and setup instructions are in the README.
